# 2026-11-17 — Month 1, Day 1

## Did
- Fixed X11: first connected without `-Y`, so no DISPLAY. Reconnected with `ssh -Y`; turtlesim window opens on the Surface.
- Configuring environment: ROS_DOMAIN_ID isolates DDS domains, even on one machine (0 when unset). ROS_AUTOMATIC_DISCOVERY_RANGE defaults to SUBNET; LOCALHOST keeps discovery on rex-agent, off the LAN and Tailscale.
- Using turtlesim, ros2, and rqt: drove turtle1 with teleop, spawned turtle2 and set the pen via rqt, remapped a second teleop to turtle2.
- Drew the node/topic graph from memory and checked it against rqt_graph.
- Understanding nodes: relaunched the second teleop as `tk2` with node and topic remaps in one command; duplicate-name warning gone.
- Arrow-key chain: teleop reads keys from its terminal (over SSH, not X11). `/teleop_turtle` publishes `geometry_msgs/msg/Twist` on `/turtle1/cmd_vel`; `/turtlesim` subscribes.
- Twist = `linear` + `angular`, in the turtle's own frame. Teleop sets `linear.x` and `angular.z` to ±2.0, a speed, not a distance. One message per key event.
- Turtlesim loop: the callback stores the latest velocity; a ~16 ms timer zeroes it after ~1 s with no command (watchdog), calculates the new pose, publishes `/turtle1/pose`, repaints.
- Measured `/turtle1/pose` at ~62 Hz, which matches the 16 ms timer.

## Broke
- Item 1 took 35 min against a 10-min slot.
- Expected two teleop nodes in rqt_graph, saw one. Both were named `/teleop_turtle` (the remap changed the topic, not the node name), and rqt_graph merges nodes by name.
- Drawing missed `/rosout` and `/parameter_events` (every node has them) and `/turtleX/pose` and `/turtleX/color_sensor` (turtlesim publishes them, nothing subscribes). Misfiled pose/color_sensor as teleop plumbing.
- Looked up `TeleportAbsolute` (a service) instead of cmd_vel's message type.
- Watchdog misconceptions: thought it zeroed velocity on the next tick, and that it was a separate high-priority process. It's an `if` in the same loop that fires after ~1 s of silence.
- `ros2 topic pub --once` moved the turtle for 3–4 s, not the expected ~1 s. Unexplained.
